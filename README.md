# Room Rent Manager — Room 33
A web app to manage bedspace rent, track payments, and generate PDF receipts.

## Features
- 📊 Dashboard with all clients, dues, and payment status
- 💰 Record rent payments with date and payment method
- 📄 Generate PDF receipts for each month
- 📲 WhatsApp share button to send receipts to clients
- 🔍 Search clients by ID or name
- 🙈 Hide/restore clients from the list
- 📱 Mobile-first responsive design

## Local Development
```bash
cd rent-app
pip install -r requirements.txt
python app.py
```
Open http://localhost:8080

## Deploy to Render
1. Push this repo to GitHub
2. Go to [render.com](https://render.com) → New → Blueprint
3. Connect your GitHub repo — Render reads `render.yaml` automatically
4. Set `ADMIN_PASSWORD_HASH` in the Render dashboard environment variables
5. Deploy!

## Environment Variables
| Variable | Description |
|----------|-------------|
| `DATABASE_URL` | PostgreSQL connection string (auto-set by Render) |
| `SECRET_KEY` | Flask secret key (auto-generated by Render) |
| `ADMIN_PASSWORD_HASH` | Hashed admin password |
| `ROOM_NAME` | Room name shown in app (default: Room 33) |

## Generate password hash
```bash
python3 -c "from werkzeug.security import generate_password_hash; print(generate_password_hash('yourpassword'))"
```
